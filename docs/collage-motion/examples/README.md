# BITFLIP / preview library

40 creator-supplied clips, published as silent 640 × 360 H.264 viewing copies at the source frame rate. Full supplied clip durations are retained. The complete source files remain separate. Media inclusion does not grant a separate reuse license.

`manifest.json` describes the individual clips. `board-demo.mp4` is a compressed viewing copy of an eight-second board exported from the actual editor.
