# BITFLIP / preview library

40 creator-supplied clips, published as silent 640 × 360 H.264 viewing copies at the source frame rate. Full supplied clip durations are retained. Original source files remain separate. Media inclusion does not grant a separate reuse license.

`manifest.json` describes the individual clips. The default presentation puts all 40 sources in Asset order, with 20 captioned shots per board page. The leading 20 are curated for the showcase; source IDs are retained.

`review-board-demo.mp4` is the current eight-second, 1080p / 24 fps presentation exported from the actual editor with borders, source captions and time displays. `board-demo.mp4` retains the earlier nine-shot example.
