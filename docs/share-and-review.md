# Share and review the portfolio

Send this single link:

**[Muwen Li — Creative Workflows](https://github.com/MuwenTriLi/creative-workflows#selected-work)**

The public repository is the front door. A reviewer can read it without a GitHub account. The project titles open case studies; **Open** links lead to products, films or interactive studios. Existing web addresses remain unchanged after the studio renaming.

## A short first visit

1. Start with **Clockwork** or **Architecture Growth** for production experience and visual direction.
2. Open **Model Breakdown Studio** for the quickest interactive example: compare assembled and exploded views, select a component, or switch models.
3. Open **Animated Storyboard** to compare moving shots. Below the board, **Source clips** provides individual playback, order, framing and include/hide controls. Hidden clips are excluded from both the board and export; removing a card does not delete the source file.
4. Open **Spatial Media Presenter** for a different task: arrange images and motion studies into a spatial presentation. Orbital Shift plays on entry.
5. VOX explores editable timed typography. TRACE starts with **your** video, then a selected target or a fixed position anchor.

## On another computer

All five studio entrances are public web pages. Bundled examples are hosted assets; visitors do not need Muwen's local folders. Imports are selected from the visitor's own device. Use a current desktop browser, preferably Chrome or Edge for the tested browser video encoders. Keep the export tab foregrounded and play the downloaded file through before delivery.

Anonymous HTTP checks establish public access without account cookies. They do **not** establish identical playback speed on every GPU, browser or connection. Actual checks and known limitations are recorded in the [functional review](functional-review.md); [4K export steps](studio-delivery.md) explain each tool's output flow. TRACE's real-time export timing remains a documented limitation.

The new Model Breakdown films are [available here](https://muwentrili.github.io/creative-workflows/model-breakdown-films/), with full duration and 30 fps playback. README animations are compact previews; the linked MP4s are the clearer viewing format.
