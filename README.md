# Creative Workflows / Muwen Li

I design tools and reusable workflows for visual creation: mechanical assets, controllable motion and browser-based creative interfaces.

Each case connects the finished visual work to the design decisions, interaction model and reusable procedure behind it.

## What to look for in this case

| Layer | Evidence |
| --- | --- |
| Visual design | A consistent mechanical language across clocks, gears and architectural forms. |
| Creative tooling | Meaningful controls for timing, gear and chain speed, guided travel and unfolding. |
| Reusable workflow | A documented method for inspecting dependencies, composing modules and checking an adaptation, packaged as a Skill. |
| Product thinking | Categorized assets, custom previews, editable settings and documentation for another creator. |

The asset project and its visual evidence are complete. The instruction-based Skill was packaged for this showcase; end-to-end execution on a new Blender task is still to be verified.
