# Creative Workflows · Muwen Li

Tools and workflows for making visual work: a commercial Blender asset product and five browser-based creative tools.

Each project presents what a creator can do with it, the decisions behind the workflow, and concrete visual evidence.

> Private review draft. The clock case includes original renders, animation previews and a control walkthrough. Other projects are being prepared; their existing web demos remain access-restricted.

## How the work is organized

The **product case** shows finished assets, interaction, design process and commercial delivery. The commercial package is distributed through its product page.

The **browser tools** provide interfaces for adjusting and previewing creative workflows. Their individual source repositories will document local setup and supported behavior once packaging and verification are complete.
