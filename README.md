# Creative Workflows · Muwen Li

Tools and reusable workflows for making visual work: mechanical assets in Blender, architectural animation, and browser-based motion tools.

This portfolio brings together three forms of work: a **commercial asset product**, a **reusable Agent Skill**, and **interactive browser tools**. Each project is organized around what a creator can do with it, the decisions behind the workflow, and the evidence available to review.

## How the work is organized

**Product case:** shows the finished asset, interaction, design process and commercial delivery. The commercial package stays on its product page.

**Agent Skill:** packages repeatable instructions and supporting resources for an agent-assisted workflow. Its setup, required software and verification steps belong with the Skill.

**Browser tools:** provide an interface for creators to adjust and preview a workflow. Their source repositories will document local setup and supported behavior. A browser tool is not automatically an Agent Skill; an agent integration would need its own usable workflow and interface.
