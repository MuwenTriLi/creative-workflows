# Collage Motion

[← All projects](https://github.com/MuwenTriLi/creative-workflows#selected-work)

**Browser tool · Original project 01 · Portfolio draft**

Turn imported images into an animated collage with layout and flash controls.

## Workflow

Import images → arrange the composition and flash timing → preview → export a video.

The local tool has been recovered. A synthetic-image test produced a playable 720p, 5-second H.264 export. A portable source package is being prepared; 4K and long exports have not been verified.
